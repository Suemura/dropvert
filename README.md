# Dropvert

macOS 用の、極めてシンプルな画像コンバータ。

ファイルをアイコンにドラッグ&ドロップすると、**元と同じフォルダ**に変換後の画像を作成し、生成を確認できたものだけ元ファイルをゴミ箱へ移動します。ドロップ時の操作はありません。ドロップするだけです。

出力形式は WebP / AVIF / JPEG / PNG から選べます（デフォルトは WebP）。設定を変えたいときだけ、アプリのアイコンをダブルクリックしてください。

## 特徴

- **ドラッグ&ドロップのみ** — Dock やデスクトップに置いたアイコンへ複数ファイルをまとめて投げる
- **元の場所に出力** — 保存先を選ぶ操作がない
- **設定は開いたときだけ** — ダブルクリックで開く 1 枚のウィンドウで、圧縮率・出力形式・元ファイルの扱い・余白の自動削除を変更できる。保存ボタンはなく、変えた瞬間に保存される。触らなければデフォルトのまま動く
- **安全な後始末** — 変換に成功したファイルだけをゴミ箱へ移動（「元に戻す」が使える）。失敗したファイルは削除しない
- **並列変換** — CPU コア数だけ同時に変換する。8 コア機で 60 枚を変換した場合、逐次実行の 53 秒に対して 11 秒
- **権限の確認ダイアログが出ない** — Finder を操作せず `NSFileManager` でゴミ箱へ移動するため、自動化の許可を求められない
- **軽量** — AppleScript の droplet + シェルスクリプトと、設定ウィンドウ用の小さなバイナリだけ。常駐プロセスなし、フレームワークなし
- **幅広い入力形式** — HEIC や AVIF なども macOS 標準の `sips` を中間変換に使って対応

## 必要環境

- macOS のみ（AVIF / JPEG / PNG への変換は標準の `sips` だけで動きます）
- WebP へ変換する場合のみ [WebP ツール](https://developers.google.com/speed/webp/download)（macOS の `sips` は WebP の書き出しに対応していないため）

```sh
brew install webp
```

出力形式が WebP のときに `cwebp` が見つからない場合、Dropvert は変換を行わずにインストール方法を表示します（他の形式に変更すればインストールなしで使えます）。

## インストール

ビルドには `swiftc`（Xcode か Command Line Tools）が必要です。設定ウィンドウをコンパイルするためだけに使うので、実行時の依存は増えません。

```sh
xcode-select --install   # 未インストールの場合
git clone https://github.com/Suemura/dropvert.git
cd dropvert
./build.sh
```

`~/Applications/Dropvert.app` が生成されます。出力先を変えたい場合は引数で指定してください。

```sh
./build.sh /Applications
```

生成された `Dropvert.app` を Dock やデスクトップにドラッグして置いておくと使いやすくなります。

## 使い方

1. 画像ファイル（複数可）を `Dropvert.app` のアイコンにドロップする
2. 変換中は「N / 全件 (X%)」の進捗が表示される（処理が終わると自動で消えます）
3. 元と同じフォルダに変換後のファイルが作られる
4. 生成を確認できたファイルがゴミ箱へ移動する（設定で「残す」に変更できます）
5. 結果が通知される（失敗があればダイアログでファイル名と理由を表示）

進捗表示の「停止」を押すと、そこまでに変換できた分だけを残して中止します。未着手のファイルは変換もされず、ゴミ箱へも移動しません。通知は「中止 — 4 件変換 / 26 件未処理」のように表示されます（出力形式と同じ形式のファイルを投げたときの「スキップ」とは区別されます）。

権限の確認ダイアログは表示されません。ゴミ箱への移動は Finder への自動化ではなく `NSFileManager` の API で行っているためです。

## 設定

アプリのアイコンを**ダブルクリック**すると設定ウィンドウが開きます。**保存ボタンはありません。**値を変えた瞬間に保存され、次のドロップから使われます。

| 項目 | 操作 | 選べる値 | デフォルト |
| --- | --- | --- | --- |
| 出力形式 | ウィンドウ右上のメニュー | WebP / AVIF / JPEG / PNG | WebP |
| 圧縮率 | スライダー | `0`〜`100`、右端で可逆（`lossless`） | `85` |
| 元ファイル | チェックボックス | ゴミ箱に入れる / 残す | ゴミ箱に入れる |
| 余白の自動削除 | チェックボックス | 削除する / しない | しない |

「デフォルトに戻す」を押すと、保存した設定をすべて消して初期状態に戻します。

設定ウィンドウを開いたままファイルをドロップしても構いません。変換はすぐに始まります。

`lossless`（可逆圧縮）の扱いは形式によって異なります。

- **WebP** — 本当に可逆で圧縮します
- **PNG** — もともと可逆なので、圧縮率の値は使いません
- **JPEG / AVIF** — 可逆圧縮がないため、最高品質として扱います

### 余白の自動削除

「余白の自動削除」を有効にすると、画像の周囲が単色で塗りつぶされている場合に、その部分を切り落としてから変換します。スクリーンショットの帯や、書き出しツールが付けた余白を取り除けます。

**完全に同じ色が続いている部分だけ**を削ります。1 ピクセルでも色が違えばそこで止まるため、被写体を削ってしまうことはありません。その代わり、JPEG のようにノイズが乗った画像では余白が少し削り残ります。

- 4 辺それぞれを見るので、片側だけの余白も削れます
- 透明な余白も削れます
- 画像全体が単色の場合は何も削りません
- GIF は対象外です（アニメーションを保つため）

**出力形式と同じ形式のファイル**（WebP 設定で `.webp` をドロップした場合など）も、余白があるときは切り落とします。この場合は切り出しのために再エンコードされるため、設定した圧縮率が適用されます。余白がなければ従来どおり何もしません。

出力は**元と同じ名前**になります。変換したファイルを検証し、元ファイルをゴミ箱へ移してから名前を引き継ぐ順序で処理します（「元ファイル: 残す」に設定している場合は名前が空かないため、`-1` が付いた名前のまま残ります）。

アニメーション WebP は対象外です（同じ形式へ書き戻すと 1 フレームに潰れてしまうため）。

設定は `defaults`（`~/Library/Preferences/io.github.suemura.dropvert.plist`）に保存されます。設定を一度も変更していなければファイル自体が作られません。

## 対応形式

出力形式が **WebP** のとき:

| 入力 | 変換経路 |
| --- | --- |
| PNG / JPEG / TIFF | `cwebp` で直接変換 |
| GIF | `gif2webp` で変換（アニメーションを保持） |
| HEIC / AVIF / BMP / PSD / JPEG XL など | `sips` で PNG に中間変換してから `cwebp` |
| WebP | スキップ（変換しない、削除もしない） |

出力形式が **AVIF / JPEG / PNG** のとき:

| 入力 | 変換経路 |
| --- | --- |
| `sips` が読める形式すべて（PNG / JPEG / TIFF / GIF / HEIC / WebP / BMP / PSD など） | `sips` で直接変換（追加のインストールは不要） |
| 出力形式と同じ形式 | スキップ（変換しない、削除もしない） |

出力形式と同じ形式のファイルは、どの形式でもスキップします（JPEG を選んで `.jpg` をドロップしても何も起きません）。**同じ形式のまま品質だけを変える「再圧縮」には使えません。**ドロップするたびに劣化が重なるのを避けるための割り切りです。

JPEG は透過を保持できません。透過のある画像を JPEG に変換すると背景が塗りつぶされます。

フォルダをドロップした場合はスキップし、結果に「フォルダはスキップ」と表示します。

## 動作の詳細

- **出力名の衝突回避** — `photo.webp` が既に存在する場合は `photo-1.webp`、`photo-2.webp` … と退避します。既存ファイルを上書きすることはありません
- **削除の判定** — 出力ファイルが存在し、かつサイズが 0 でないことを確認したうえで初めてゴミ箱へ移動します。「元ファイル: 残す」に設定した場合は、この移動そのものを行いません
- **失敗時** — 出力の残骸を削除し、元ファイルはそのまま残します
- **書き込み権限がない場所** — 変換せずに理由を報告します
- **メタデータ** — WebP へ変換する場合は ICC プロファイルを引き継ぎます（`-metadata icc`）
- **並列変換** — CPU コア数（`sysctl -n hw.ncpu`）だけ同時に変換します。同時に走るプロセスが同じ出力名を掴まないよう、出力ファイルは `noclobber` で予約してから書き込みます
- **ファイル名に改行を含むファイル** — 変換せずに理由を報告します（内部で使うファイルリストが行単位のため）

## ビルド時の設定

同時に変換する数だけは設定画面に置いていません。変更する場合は `Dropvert.applescript` の先頭を編集し、`./build.sh` を再実行してください。

```applescript
property parallelism : "0"
```

`parallelism`（同時に変換する数）:

- `"0"` — CPU コア数を使う（デフォルト）
- `"1"` — 逐次実行
- `"2"` 以上 — 指定した数だけ同時に変換

## 構成

```
dropvert/
├── Dropvert.applescript  # droplet 本体。ドロップ受付、進捗表示、結果通知
├── Prefs.swift           # 設定ウィンドウ（ダブルクリックで開く）
├── Trim.swift            # 単色余白を測り、切り出す矩形を返す
├── run.sh                # 複数ファイルを並列変換し、結果を集約する
├── convert.sh            # 1 ファイルを変換するロジック
├── trash.js              # ゴミ箱へ移動する JXA スクリプト
├── build.sh              # アプリをビルドし、ad-hoc 署名を付け直す
├── lint.sh               # 静的チェック（開発用。アプリには同梱されない）
├── .editorconfig
├── README.md
├── CLAUDE.md
└── LICENSE
```

これらは Dropvert.app 内の `Contents/Resources/` に同梱され、droplet から呼び出されます（`Prefs.swift` と `Trim.swift` はコンパイルしたバイナリが入ります）。シェルスクリプトは単体でも実行できます。

```sh
./convert.sh path/to/image.png 85          # 第 3 引数を省略すると WebP
./convert.sh path/to/image.png 85 avif     # webp / avif / jpeg / png
./convert.sh path/to/image.png 85 webp 1   # 第 4 引数の 1 で余白を削る
```

標準出力は次のいずれかです（元ファイルの削除は行いません）。

- 生成されたファイルのパス（成功）
- `SKIP`（対象外）
- `FAIL:理由`（失敗）

複数ファイルをまとめて変換する場合は `run.sh` を使います。第 1 引数は 1 行 1 パスのファイルリスト、第 3 引数は並列度、第 5 引数は出力形式、第 6 引数は余白の削除です。

```sh
ls ~/Pictures/*.png > /tmp/list.txt
./run.sh /tmp/list.txt 85 0
./run.sh /tmp/list.txt 85 0 "$(mktemp -d)" avif 1
```

標準出力はタブ区切りのサマリのみで、変換した件数・スキップ件数・失敗の一覧と、成功した元ファイルのパスを並べたリストのパスを返します。元ファイルの削除はここでも行いません（元の名前へ戻すリネームも、ゴミ箱への移動を担当する droplet 側の仕事です）。

## 開発

コードを変更する場合は、静的チェックを 1 コマンドで実行できます。

```sh
./lint.sh
```

シェルスクリプトの構文チェック（`bash -n`）、AppleScript / JXA（`osacompile`）、Swift（`swiftc -typecheck`）は追加インストールなしで動きます。shellcheck と shfmt によるチェックも行うには、次をインストールしてください（未インストールの場合、その項目は `SKIP` と表示されます）。

```sh
brew install shellcheck shfmt
```

変換のテストも 1 コマンドで実行できます。テスト素材と出力は一時ディレクトリの中だけに作られ、手元のファイルには触れません。

```sh
./tests/run.sh
```

実行には `webp`（`cwebp` / `gif2webp` / `webpmux`）が必要です。Dropvert を使うためにインストール済みのはずですが、入っていなければ `brew install webp` を実行してください。

push と Pull Request では GitHub Actions（`macos-latest`）が同じチェックとテスト、ビルド・署名検証を自動で実行します。ドラッグ&ドロップの操作そのものは自動化されていないため、手元での確認が必要です。

## 名前について

`Dropvert` = drop + convert。無関係の同名 Web サービス（dropvert.com）が存在しますが、本プロジェクトとは一切関係ありません。
